# EJSTeste

Express + EJS web application with TypeScript.

## Installation

```bash
git clone https://github.com/juninmd/EJSTeste.git
cd EJSTeste
npm install
```

## Usage

**Development** (with hot reload via `tsx`):
```bash
npm run dev
```

**Build** (compile TypeScript to JavaScript):
```bash
npm run build
```

**Production**:
```bash
npm run build
npm start
```

Open [http://localhost:4000](http://localhost:4000) in your browser.
